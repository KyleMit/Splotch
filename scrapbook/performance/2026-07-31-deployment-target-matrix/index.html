How to read this snapshot

Drawing dots show the median P95/P99 and worst maximum across repeated blank-paper runs. Raw drawing tables and action samples are re-scored with the current metric definitions. The committed JSON preserves every renderer phase, the source commit for each run, and the source artifact and commit for each action result.

Action sources are applied in manifest order. A focused capture replaces only its declared labels; all other labels retain their earlier measurement and provenance. Profiling controls such as the idle-frame sample remain in normalized data but are omitted from the user-action comparison.
