Toolbar icon alignment

Every drawing-toolbar icon rasterized and measured — alpha bounding box, per-side padding, and alpha-weighted centroid — then re-framed so the visual weight sits centered with a consistent keyline.

7 re-framed 4 already true

Prompted by the camera icon reading as if it hugs the bottom-left of its button. Each icon below was rasterized at 512×512 from its SVG viewBox (the exact square the toolbar button scales it into), and measured: padding per side (left / right / top / bottom, % of the box), extent (content bounding-box size), and the alpha-weighted centroid — where the ink's visual mass actually sits, offset from the box center. The camera's diagnosis: its bounding box was centered, but only because the flash sparks stretch it up-right — the heavy body sat 6.8% left and 5.2% low. Bounding-box centering isn't visual-weight centering.

Reading the tiles

Each tile shows the icon exactly as its button frames it. Targets: blocky solid shapes (sticker book, eraser, undo) at a ~91–93% keyline; thin diagonal tools (the brush faces) at ~87–89%; wide or sparkle-sprawling compositions may run to ~96% since their edge elements are visually light.
