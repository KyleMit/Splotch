# React Strict DOM vocabulary and native adapters

Splotch's app entry is `src/index.ts`, which registers `ProbeApp` and mounts
`src/rsdDrawing/RsdDrawingScreen.tsx`. React Strict DOM is the selected shared UI renderer
(ADR-0182). Drawing, history, AI, settings and picture export have their own owners; components
subscribe to those owners and issue actions through them.

The `architecture` skill and `docs/ARCHITECTURE.md` hold the source map and canonical product names.
The `design` skill holds tokens, copy, primitives and styling rules. This guide records the renderer
boundaries that matter when extending the shared UI.

## Layout boundaries

| Owner                                  | Contract                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------ |
| `src/rsdDrawing/NativeFrame.tsx`       | Safe-area provider, window background and outer app frame.                                 |
| `src/rsdDrawing/NativePaper.tsx`       | Native drawing surface and measured paper geometry.                                        |
| `src/rsdDrawing/NativeScrollAreas.tsx` | Explicit native scrolling regions; `overflow` on an RSD view does not create a ScrollView. |
| `src/rsdDrawing/ModalShell.tsx`        | Platform modal shell, bounded content, orientation support and presence.                   |
| `src/rsdDrawing/RsdActionsPanel.tsx`   | Drawing action tiles and drawer controls.                                                  |
| `src/rsdDrawing/RsdColorPicker.tsx`    | Honeycomb color selection with shared palette and trim geometry.                           |

Paper dimensions stay locked while a drawing exists; presentation contains that paper within the
available viewport. Safe-area insets and drawing coordinates are different spaces. Read
`docs/SAFE-AREA.md` and `docs/ORIENTATION.md` before changing their mapping.

Native ink renders through Skia (ADR-0178); browser rendering is selected through `.web` adapters.
Metro chooses platform files at build time (ADR-0179). A runtime platform check cannot replace this
boundary when an import would pull native modules into the web startup graph.

## Tokens and controls

`src/lib/design/tokens.ts` is authoritative. `src/rsdDrawing/tokens.css.ts` is generated by
`tools/migration/gen-rsd-drawing-tokens.mjs`; its check rejects drift. Use the generated RSD token
variables in shared component styles, and consult `src/lib/design/tokenUsage.ts` for their meaning.

The shared primitives live in `src/rsdDrawing/`: `RsdButton`, `RsdIconButton`, `RsdTextField`,
`RsdToggleSwitch`, `RsdSegmentedPicker`, `RsdSlider`, `RsdTextLink` and `RsdFlyoutMenu`. Read each
primitive's current props and mounted tests before adding a variant. A closed mode vocabulary
belongs in its type, and a new option needs a production caller.

Use the primitive's semantic role and state. Selection controls expose their radio/switch checked
state; disabled controls keep the established disabled treatment. Web focus rings use
`src/rsdDrawing/focusRing.ts` and the global web rules rather than unsupported native outline
styles. Native slider accessibility actions and relative dragging belong to the slider host; visual
RSD children do not independently own its value.

Icons are generated into `src/rsdDrawing/icons.generated.ts` and rendered by `RsdIcon`. Deferred
assets stay outside the startup path. Run `npm run build:site` after changing runtime import edges;
its first-paint, controls and per-document caps enforce the actual export graph.

## Settings and dialogs

`src/settings/` owns the validated settings codec, write queue and feature choices;
`src/parentCenter/` owns parent policies. Compact and wide settings shells consume shared section
owners. Do not reproduce a policy from raw fields in a component.

Settings loading, write failure, reset and late async settlement are explicit owner states. Mounted
contracts exercise these transitions through real factories. Read the stored schema version from
`src/settings/soundSettingsCodec.ts` rather than copying a version number into a guide or test.

Modal presence owns entry, exit and interrupted dismissal. `ModalShell` and the platform scrim
adapters own native/web differences. The iOS blur view lives behind `src/platform/backdropBlur.tsx`;
web uses `ModalScrim.web.tsx`. A parent changing Button Size or Volume previews through the current
settings draft owners; components must preserve their commit and failure semantics.

## Text and scrolling

RSD text uses the app's generated font tokens. React Native `Text` and `TextInput` consumers import
from `src/drawing/Text.tsx`; `src/platform/shippingFont.tsx` and its web adapter own font loading.
Native Dynamic Type and Android font scale can alter layout after mount. Use the existing fitted and
whole-word text adapters for bounded labels rather than breaking words or fixing the global font
scale.

Native scroll regions use explicit adapters. On the web, document pages and their section links must
remain readable without JavaScript. The export checks pages without scripts and verifies safe-area
layouts, while mounted tests cover native row, modal and text behavior.

## Feature ownership and verification

| Surface                                                 | Owner                                                                        |
| ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| AI transport, credentials, recovery and late settlement | `src/ai/`                                                                    |
| AI progress, result and report UI                       | AI components in `src/rsdDrawing/`                                           |
| Installed coloring books and integrity                  | `src/offlineLibrary/` and platform library adapters                          |
| Picture saving and failed-save recovery                 | `src/export/` and platform save adapters                                     |
| Information pages and release history                   | `src/information/`                                                           |
| Browser page documents and web-only admin               | `src/pageDocument/`                                                          |
| Installation and PWA lifecycle                          | `src/install/`, platform service-worker adapter and `src/lib/pwa/updates.ts` |

Run `npm run check`, `npm run lint`, and the mounted RSD contracts with
`npm run test:migration:rsd-selection`. `docs/TESTING.md` describes targeted RN-export Playwright
checks and native launch smokes. Historical template comparisons and captures document their
original runtime; they do not establish RN parity. The cutover's fourteen owner gaps remain recorded
in the E2E disposition tables under `docs/scratchpad/2026-10-21-rn-e2e-dispositions/`.
