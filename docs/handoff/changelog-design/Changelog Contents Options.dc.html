Turn 1 · Changelog contents
Three ways to replace the two-column contents grid
The two-column grid asks you to read in a Z pattern against a list that is already ordered newest-first. Each option below keeps the same anchors and the same pinned light palette, and only changes how the list is presented at widescreen.
1a Sticky rail Contents moves out of the reading column into a left rail that follows you down the page. My recommendation: it is the only option that earns the extra width instead of spending it.
