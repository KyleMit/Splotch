# Guards and verdicts

Every capture carries a trust ledger: one entry per guard and verdict, each `verified`, `failed`,
`unrecorded` (should have run on this transport and did not; read as failed) or `not-applicable`
(does not apply to this transport by the package's table, never by omission). Guards run before
measurement and refuse with exit 2; verdicts run after and fail with exit 1 once the artifact is
written. The order below is the order they run.

## Guards (before measurement)

| Guard                    | What is checked                                                              | How                                                                                     | What the app provides                         | Not applicable when                         |
| ------------------------ | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------- |
| `refused-build-variant`  | The build directory does not hold a variant the contract refuses             | Marker file present and the variant's dropped files absent                              | `build.refusedVariants`                       | `build.mode: 'url'`                         |
| `build-seams-present`    | The served page carries the instrumentation seams                            | `build.seams.present` (default `page.hydrated`) is true                                 | The seam env vars and a page expression       | never                                       |
| `served-build-identity`  | The port serves the build `outputDir` holds, or the stamp the app expects    | Digest of the entry module and every immutable chunk, or the `stamp` expression         | `build.identity`                              | `allowForeignBuild` (recorded as tolerated) |
| `page-identity-nonce`    | The page's query string echoes this run's nonce                              | `?probe=<nonce>` compared in the bootstrap; a mismatch stands the tab down              | A route that ignores `HARNESS_QUERY_PARAMS`   | packaged pages loading a fixed URL          |
| `route-hydrated`         | The client bundle ran                                                        | `page.hydrated` true within the hydration timeout; one `?rehydrate=1` reload allowed    | An expression false in server-rendered markup | never                                       |
| `page-prepared`          | The app's preparation procedure met its postcondition                        | `page.prepare` compiled for the channel                                                 | Optional procedure                            | no `prepare` declared                       |
| `window-fills-screen`    | The browser window is the full screen                                        | Window rect versus `screen.width` through the driver                                    | nothing                                       | desktop and packaged targets                |
| `tab-responsive`         | The selected tab runs JavaScript                                             | A bounded evaluate; a backgrounded WebKit tab hangs rather than fails                   | nothing                                       | channels other than `webkit-inspector`      |
| `foreground-package`     | The foreground app is the one the capture labels                             | `dumpsys window` or the WebDriver context list                                          | `native.android.package`                      | desktop                                     |
| `runtime-user-agent`     | The page's user agent identifies the labelled runtime                        | UA tokens per `captureRuntime`                                                          | nothing                                       | never                                       |
| `packaged-origin`        | A packaged capture's page is the packaged origin, not a remote preview       | `location.origin` against `native.*.packagedOrigin`                                     | The packaged origins                          | browser targets                             |
| `entry-module-match`     | The entry module the device loaded is the one the host serves                | `document.scripts` against the served HTML                                              | `build.identity.entryModule`                  | `stamp` identity                            |
| `service-worker-blocked` | No service worker can serve a previous shell during the capture              | Registration blocked before navigation; existing registrations unregistered             | nothing                                       | packaged pages                              |
| `dimension-observed`     | Each requested dimension was set and reads back as requested                 | `Dimension.set` compiled for the channel, then `Dimension.read`                         | `state.dimensions`                            | no dimension requested                      |
| `committed-tool`         | The engine committed the selected tool                                       | `tools.select` then `tools.committed`; pen is selected explicitly like every other tool | `tools`                                       | scenarios without a tool                    |
| `menus-dismissed`        | No menu is laid out over the surface                                         | `tools.dismissMenus` postcondition                                                      | `tools.dismissMenus`                          | scenarios without a tool                    |
| `hit-test-surface`       | A touch at the surface centre would land on the surface                      | `elementFromPoint` resolves inside `page.hitTestAncestor`                               | `page.hitTestAncestor`                        | never                                       |
| `prime-verified`         | The tool's prime procedure met its report twice, before and after the settle | `PrimeProcedure.apply` polled within budget, then `verify`                              | `tools.prime`                                 | tools without a prime                       |

## Verdicts (after measurement)

| Verdict                 | What is checked                                                                          | How                                                                                | Not applicable when                                                                                  |
| ----------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `input-received`        | The page recorded pointer input at all                                                   | Non-zero moves in the events table; the pulse heartbeat on the plan-polled channel | never                                                                                                |
| `input-fidelity`        | The input was hand-shaped enough to score, per the app's expectations for this runtime   | `inputFidelity(summary.input, captureRuntime, expectations)`                       | transports whose `reports.fidelity` is false (desktop)                                               |
| `refresh-regime`        | The observed beat sits in the target's declared regime and is not mixed                  | `refreshRegimeVerdict`                                                             | transports whose `reports.refreshRegime` is false; `refreshRegime: null` targets are banked unscored |
| `painted-output`        | The output surfaces changed                                                              | Digest pair around the capture per `page.outputSurfaces.proof`                     | never                                                                                                |
| `gesture-plan`          | The plan the artifact records is the plan the scenario declares                          | `evidence.gesturePlan.id`                                                          | `probe-synthetic` and `human` input                                                                  |
| `gesture-repeats`       | The recorded repeats equal the plan's                                                    | `evidence.gesturePlan.repeats`                                                     | as above                                                                                             |
| `prime-between-passes`  | Every between-pass prime saw a new trusted lift and reported clean                       | `evidence.prime.betweenPasses`, count `repeats - 1`                                | tools without a prime                                                                                |
| `repeated-action-proof` | The repeated control reduced history depth by exactly N and changed pixels on every step | `evidence.repeatedAction`                                                          | no `repeatedAction`                                                                                  |
| `capture-runtime`       | The artifact's runtime, transport, origin and package agree                              | `runtimeOf(artifact) !== 'contradictory'`                                          | never                                                                                                |
| `host-quiet`            | Host load per core stayed under the threshold across the window                          | Load average bracketed around the capture; raw samples kept                        | a witness on device targets unless the rig asks for it as a gate                                     |
| `instrument-restored`   | Every instrument's `restore` ran                                                         | Registered at `start`, confirmed at exit including on interrupt                    | no instrument that changes device state                                                              |
