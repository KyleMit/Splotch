# Slice: coloring · saving · install/update/offline · errors/Back · platform

Pinned at 64a9ca53a; read-only. Shipping = `web/src/lib` (S/),
`android/app/src/main/java/art/splotch/app`, `ios/App/App`. RN =
`experiments/native-architecture/src` (R/),
`.../android/app/src/main/java/art/splotch/migration/probe`, `.../ios/HelloWorld`. The live RN tree
is `ProbeApp.tsx → RsdDrawingScreen`. `DrawingScreen.tsx`, `ColoringPagePicker.tsx`,
`settings/SoundSettingsSheet.tsx`, `settings/ColoringBookSetting.tsx` and every
`platform/DrawingModal.tsx` user are legacy and unreachable. Some RN tests still mount them:
native-offline-picker, native-save-to-photos-mounted, native-system-back-mounted (behaviour cases),
native-drawing-recovery. Coverage those tests claim does not apply to the product.

"Guard" means a test that reads or imports the shipping side and compares it. One-sided RN tests are
listed as "(RN only)".

## 4. Concrete differences

Each item gives the shipping evidence (S/…, or a native path), then the RN evidence (R/…), then the
user-visible effect. Severity is in brackets.

### High

1. **[H] Android 7–10 cannot save a picture at all.**
   * Shipping: PhotoLibraryPlugin.java:116-143 (MediaStore on 29+; legacy write or app-media
     fallback on 24–28); AndroidManifest.xml:47.
   * RN: R/platform/photoLibrary.ts:9-11,22-23 returns 'unavailable'; RN AndroidManifest.xml:7
     removes the permission; R/export/pictureSave.ts:28-30 adds "Saving to your gallery needs
     Android 11 or later."
   * minSdk is 24 on both sides, and docs/COMPATIBILITY.md keeps the API 24 floor specifically for
     gallery saves.
2. **[H] With Auto-Save on Delete on, a failed save aborts the Clear.**
   * Shipping: S/components/ClearButton.svelte:67-68 and S/drawing/saveOnDelete.ts:26-29 clear
     immediately and save in the background, holding the blob.
   * RN: R/useDrawingScreen.ts:442-447 returns early and the picture stays on the paper. RN also
     waits for the save (and any iOS prompt) before clearing.
   * Combined with item 1, Clear never works on Android 7–10 while the setting is on.
3. **[H] Unsaved pictures are not persisted.**
   * Shipping: S/drawing/unsavedPictureStore.ts:6-10,94-111 and
     S/state/saveFailure.svelte.ts:231-234 (IndexedDB, restored at boot).
   * RN: R/export/saveFailure.ts:3-6 (memory only).
   * iOS terminates an app whose Photos access changes in Settings, so the banner and Try again
     vanish exactly after "Open Settings".
4. **[H] Coloring downloads never start until the picker is opened, every session.**
   * Shipping: S/boot/coloringPacks.ts:35-37 (native at boot); S/routes/+page.svelte:106-109 and
     boot/coloringPacks.ts:103-114 (web: 3rd stroke, picker open, or idle when packs already exist).
   * RN: R/offlineLibrary/controller.ts:116-126 `allowed()` requires `engaged`, which only
     R/offlineLibrary/useOfflineLibrary.ts:27-29 sets on picker open.
5. **[H] RN web never downloads books on Safari, Firefox or desktop Chrome by default.**
