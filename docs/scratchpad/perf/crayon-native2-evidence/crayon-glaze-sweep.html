Crayon glaze sweep — perOpGlazeReturn

Yellow drawn first, then blue across it. Down the rows the per-op return rises, so the first crossing keeps more of the crayon's own colour. Across the columns the blue is redrawn, so each row shows how fast that value walks the crossing toward blue.

The highlighted top row is the web pipeline — the appearance that ships today on Safari, glazed once per pass. It is the reference each candidate below is trying to resemble, not another candidate.

The number under each cell is the median rgb at the crossing. Read the TREND along a row or a column, not a single cell: the wax is a binary tooth, so which pits fall in the sample window varies with the pattern seed and an individual value carries real variance.

Pixels only. Rendered in desktop WebKit, which reproduces the device's colour but not its frame cost — never read performance off this sheet.
