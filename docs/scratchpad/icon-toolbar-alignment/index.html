Toolbar icon alignment

Every icon rasterized and measured — alpha bounding box, per-side padding, and alpha-weighted centroid — then rebuilt as natively centered assets on a canonical grid. Full 74-icon corpus sweep at the bottom.

10 rebuilt 64 verified as-is

Prompted by the camera icon reading as if it hugs the bottom-left of its button. Each icon below was rasterized at 512×512 from its SVG viewBox (the exact square the toolbar button scales it into), and measured: padding per side (left / right / top / bottom, % of the box), extent (content bounding-box size), and the alpha-weighted centroid — where the ink's visual mass actually sits, offset from the box center. The camera's diagnosis: its bounding box was centered, but only because the flash sparks stretch it up-right — the heavy body sat 6.8% left and 5.2% low. Bounding-box centering isn't visual-weight centering.

Reading the tiles

Each tile shows the icon exactly as its button frames it. Targets: blocky solid shapes (sticker book, eraser, undo) at a ~91–93% keyline; thin diagonal tools (the brush faces) at ~87–89%; wide or sparkle-sprawling compositions may run to ~96% since their edge elements are visually light.

Native assets, not re-framed windows

Every corrected icon is a purely new asset: the alignment transform is baked into the path, circle, and ellipse coordinates themselves (arc radii scaled, rotate-positioned sparkle ellipses recomposed about their own centers), and each file carries a clean canonical viewBox="0 0 1000 1000" — no offset viewBox window layered over the original artwork. Each bake was verified by rasterizing the baked file against the framed version at 512px: worst case 0.03% differing pixels, all antialiasing rounding.

The canonical grid then went corpus-wide (ADR-0125): all 73 <Icon> assets now share viewBox="0 0 1000 1000" — the dozen source grids (Material's 0 -960 960 960 and 0 0 24 24, bespoke 0 0 1254 1254, 2 2 56 56, …) are gone, rebased by npm run gen:icon-viewbox with per-file pixel verification (worst metric drift 0.2%, one raster pixel). Only the mascot splotchy.svg keeps its own frame, since it renders by intrinsic size through a URL import. iconViewBox.test.ts enforces the grid, so a freshly imported Material icon fails the unit tier until rebased.
