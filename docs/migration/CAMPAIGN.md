## Acceptance discipline

Before a consequential probe, name its uncertainty, actual released-system owner, acceptance
predicate, expected positive, intended rejecting control and claim limits. Check real boundaries
before expanding fixtures. Ask Claude for plausible false passes and false rejections. Unexpected
setup failures are preserved separately and never count as rejecting controls.

Moving source/base/environment invalidates only affected receipts. Preserve tested source, findings,
actual conversation identity and review provenance before cleanup. Reconcile moving main at
appropriate phase/release boundaries; new distributed sources join the upgrade inventory. Invalid
provenance, material unresolved findings, unintended control failure and stale inputs halt dependent
acceptance. A retained/hybrid result remains incomplete until its applicable final gates pass. A
hardware or external approval blocker cannot be replaced by simulator timing or agreement.
