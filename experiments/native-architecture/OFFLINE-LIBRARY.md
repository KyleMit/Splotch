# Offline coloring library source candidate

The parent controls can download the seven additional complete coloring books. Dinosaurs is the
first additional book. Installation verifies the finite approved HTTPS file inventory, byte lengths
and SHA-256 digests before publishing its marker. Saved pictures retain their artwork revision when
parents remove a book, including after offline relaunch.

Generate the retained asset catalog directly with
`node --experimental-strip-types tools/migration/gen-offline-catalog.mjs`. Add `--check` to verify
its checked-in output. The root package manifest remains the exact authenticated joint-graph input;
adding a script would invalidate its existing evidence boundary. The direct CLI avoids changing the
script catalog or any dependency, lockfile, patch or build policy (ADR-0019).

`tools/migration/inputs/offline-library-source-extension.json` retains the original maintained
native and N1 adapter bytes, their original digests, and the finite exact source edits. Its
authenticated reader replays these edits on the original template transformations. Three owned
native bridge sources are explicit additions to the provenance receipt. The upstream template
archive, metadata, manifest and original transformation recipes remain inputs to that replay. The N1
adapter guard verifies the retained original Git blobs before replaying the feature extension;
existing save and reopen behavior is also exercised through the production file adapters.

Downloads pause when the app enters the background. A terminated JavaScript transfer is discarded on
the next launch; published and retained books are reverified. This source does not claim durable OS
background jobs. Native compilation, real OS storage/network/cancellation behavior, rendered native
offline reopen/export, and any future durable background transfer adapter remain runtime gates. No
legacy data or jobs are imported. This candidate selects no migration framework.
